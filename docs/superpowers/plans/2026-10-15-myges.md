# Plan : myGES comme source de données (emploi du temps + notes)

Date : 15/10/2026. Demande : remplacer le flux ICS Edusign par myGES, emploi du temps plus à jour,
notification à chaque nouvelle note, consultation des notes dans le menu.

## Décision

Source retenue : **API mobile Kordis** (`authentication.kordis.fr` + `api.kordis.fr`), documentée
dans `docs/myges-api-kordis.md`. Le portail web JSF (`docs/myges-web-portail.md`) est gardé en
référence : trop fragile (ViewState, HTML des notes à mapper par en-têtes, détail d'un cours non capturé).

Le flux iCal reste disponible (réglage « Source du calendrier ») : il sert toujours aux calendriers
des potes (pauses communes) et aux utilisateurs sans compte myGES.

Identifiants : fichier `~/Library/Application Support/EduBar/myges-credentials` (0600, dossier 0700),
même choix que `feed-url` (le Trousseau perd l'accès à chaque mise à jour, signature ad-hoc). Le
jeton OAuth reste en mémoire ; on se reconnecte à l'expiration (`expires_in`) ou sur 401.

## Lots (un agent sonnet à la fois, tests Swift Testing)

### A · EduBarCore : modèles et parsing myGES (pur, testé)
- `Sources/EduBarCore/MyGES/KordisToken.swift` : `KordisToken.parse(location:)` lit le fragment
  (`access_token`, `expires_in`, `token_type`, `uid`) sans décoder les `+`.
- `Sources/EduBarCore/MyGES/GESAgenda.swift` : `GESEvent` Decodable tolérant (`result` enveloppe,
  dates en ms, `rooms[]`, `discipline`, `teacher`, `modality`, `type`), `GESAgenda.courses(from:)`
  → `[Course]` (id = `reservation_id`, titre = `name`, salle = `rooms[].name` joints par « · »,
  campus si présent). Nouveaux champs optionnels sur `Course` : `teacher`, `modality` (Codable
  compatible avec les archives JSON existantes).
- `Sources/EduBarCore/MyGES/GESGrades.swift` : `GradeBook` (par matière : `course`, `grades: [Double]`,
  `exam: Double?`, `average: Double?`, `ccAverage: Double?`, `coef`, `ects`, `teacher`, `trimester`),
  décodage tolérant (null, "", 0, "12,5", nombre, objets `{grade|value}`), `GradeDiff.newGrades(old:new:)`
  → liste de `NewGrade` (matière, libellé « CC2 » / « Examen », valeur), et
  `GradeDiff.notifications(_:)` → `[PendingNotification]`.
- Fixtures JSON reconstituées dans `Tests/EduBarCoreTests/Fixtures/` ; tests `MyGESTests.swift`.

### B · EduBar : client réseau, stores, intégration AppModel
- `Sources/EduBarCore/MyGES/Credentials.swift` : `MyGESCredentials` (login, mot de passe) stocké via
  `FeedFile(name: "myges-credentials")`, format `login\npassword`.
- `Sources/EduBar/MyGESClient.swift` : URLSession sans suivi de redirection, User-Agent navigateur,
  `authenticate()`, `agenda(from:to:)`, `years()`, `grades(year:)`, re-auth une fois sur 401,
  erreurs lisibles (`badCredentials`, `http(code)`, `unavailable`).
- `CalendarStore.refresh(from:)` devient agnostique : `refresh(fetch: () async throws -> [Course])`
  ou surcharge `refresh(myGES:)` ; cache JSON des cours pour la source myGES. Plage : lundi de la
  semaine courante −7 j → +8 semaines.
- `Sources/EduBar/GradesStore.swift` : cache 0600 `grades.json`, `refresh()`, `lastUpdated`,
  `lastError`, `newGrades` (diff).
- `AppModel` : `calendarSource` (`.ical` | `.myges`, UserDefaults `calendarSource`), identifiants,
  `saveCredentials(login:password:)` (teste l'auth puis écrit), `notifyNewGrades` (défaut true),
  boucle de 15 min rafraîchit agenda ET notes, notifications des nouvelles notes via `Notifier`,
  `showingGrades`.
- CLI de diagnostic : `EduBar --myges-dump` imprime le JSON brut (agenda 2 semaines + notes) sur stdout.

### C · Interface
- `SettingsPanel.account` « Compte myGES » (symbole `person.crop.circle`) : identifiant, mot de passe
  (SecureField), bouton « Se connecter », message ok/erreur, bouton « Oublier ». Section Calendrier :
  picker de source + champ iCal existant seulement si source iCal.
- Notifications : interrupteur « Nouvelle note ».
- `Views/GradesView.swift` : liste par matière (moyenne, notes CC, examen, coef), bouton retour ;
  bouton `graduationcap` dans le pied de `DayView` ; branche dans `MenuContent`.
- Snapshot `--demo` : notes factices pour la capture README.
